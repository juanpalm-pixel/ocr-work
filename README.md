# OCR practicals

This repository has two exercises. Start with Kraken at the command line, then use eScriptorium for the Chinese historical print pages.

1. [Stage 1: OCR with Kraken](stage_1/README.md) — run binarization, line segmentation, and recognition on two pages from *Linguistic Survey of India*, Volume III, Part I. Compare a prose page with a page containing linguistic forms and a table.
2. [Stage 2: eScriptorium and Kraken](stage_2/README.md) — review 20 scanned Chinese historical print pages and their provisional PAGE XML annotations in a local Docker-based eScriptorium instance.
